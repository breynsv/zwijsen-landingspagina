Veelgestelde vragen

Heb ik een CV nodig?

Nee. Je vult acht korte vragen in en laat je gegevens achter — dat volstaat. Heb je wel een CV bij de hand, dan mag je het toevoegen, maar het is niet verplicht.

Ik heb nog geen VCA-attest. Kan ik dan solliciteren?

Zeker. VCA is een vereiste om op de werf te staan, maar je hoeft het niet vooraf te hebben. Wij plannen en betalen die opleiding voor je.

Hoe snel krijg ik antwoord?

Binnen één werkdag krijg je een telefoontje. Je krijgt altijd een duidelijk antwoord, ook als het geen match blijkt te zijn.

Ik heb weinig werfervaring. Maak ik kans?

Ja. Een eerste ervaring is een plus, geen voorwaarde. Wat telt is een technische achtergrond en de goesting om bij te leren. Je start altijd naast een ervaren collega.

Is mijn sollicitatie vertrouwelijk?

Volledig. Je gegevens komen enkel bij onze personeelsdienst terecht en worden niet gedeeld met derden. Je huidige werkgever verneemt hier niets van.
